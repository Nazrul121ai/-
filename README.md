# চালক ভাই – APK বানানোর নিয়ম

1. github.com এ গিয়ে নতুন একটা Repository খুলুন (যেমন: chalok-bhai)।
2. "uploading an existing file" চাপুন, এই ZIP-এর ভেতরের সব ফাইল ও ফোল্ডার (`.github` সহ) আপলোড করুন, তারপর Commit করুন।
3. Repository-র **Actions** ট্যাবে যান। "Build APK" চলবে (৩-৫ মিনিট)।
4. শেষ হলে ওই রানে ক্লিক করুন, নিচে **Artifacts** থেকে `chalok-bhai-apk` ডাউনলোড করুন।
5. ZIP খুলে `app-debug.apk` ফোনে ইনস্টল করুন।

কনটেন্ট বদলাতে: `www/data.js` ফাইল এডিট করুন (প্রশ্ন, উত্তর, সাইন, কুইজ, চাকরি)।

নোট: ভয়েস ("শুনুন") বাটন ফোনের Bengali Text-to-Speech ইঞ্জিনের উপর নির্ভর করে। না থাকলে Google Text-to-Speech অ্যাপে বাংলা ভাষা ডাউনলোড করুন।

## চাকরি অনলাইনে আপডেট করা (অ্যাপ নতুন করে বানানো ছাড়াই)
1. GitHub repository-তে `jobs.json` ফাইলটা এডিট করুন (কাঠামো ফাইলের ভেতরে দেওয়া আছে)।
2. ফাইলটির Raw লিংক কপি করুন (ফাইল খুলে "Raw" চাপলে পাবেন, যেমন `https://raw.githubusercontent.com/আপনার-নাম/repo/main/jobs.json`)।
3. `www/data.js` ফাইলে `const JOBS_URL = '...';` এর ভেতর ওই লিংক বসান, তারপর একবার APK বানান।
4. এরপর থেকে `jobs.json` বদলালেই ব্যবহারকারীর অ্যাপে নতুন চাকরি আসবে।
5. প্রতিটি চাকরিতে `"deadline": "2026-12-31"` দিলে ওই তারিখের পর চাকরিটি অ্যাপ থেকে নিজে সরে যাবে।
6. `"kind"`: `govt` (সরকারি), `local` (দেশি), `foreign` (বিদেশি)।

## নতুন ফিচার (ভাষা, ফন্ট, লগইন)
- ভাষা: হোমের উপরের EN / বাং বাটন বা প্রোফাইল পেজ থেকে বদলানো যায়। নতুন অনুবাদ `www/i18n.js` এ যোগ করুন।
- ফন্ট: Noto Sans Bengali অ্যাপের ভেতরেই আছে (`www/fonts`), তাই সব ফোনে একই চেহারা।
- লগইন, ব্যাকআপ ও পেইড কোর্স: `SETUP.md` দেখুন।
